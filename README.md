# SamuraiFX AI

Simple single-file Railway Telegram bot focused only on GBPJPY.

Upload these files directly to the root of your GitHub repository:

- main.py
- requirements.txt
- Procfile
- .env.example
- README.md

Railway Variables:

- TELEGRAM_BOT_TOKEN
- OPENAI_API_KEY
- OPENAI_MODEL

Recommended OPENAI_MODEL:

gpt-4.1-mini

Railway start command:

python main.py
